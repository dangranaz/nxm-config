Precedenza della configurazione

nxm-config risolve i valori di configurazione da file TOML, poi sovrascrive le chiavi supportate dalle variabili d'ambiente NXM_*.

Un risultato, non variabili sparse

  • La lettura del file restituisce GeneralConfig tipizzato.
  • I driver e gli URL del database vengono normalizzati in modo sicuro.
  • Ogni valore viene validato prima di uscire dal loader.

Precedenza chiara

  • I valori del file vincono sulle integrazioni di default.
  • NXM_* vincono su tutto il resto.
  • Le porta zero e gli URL vuoti vengono rifiutati.

Overrides supportati

  • NXM_DATABASE_DRIVER, NXM_DATABASE_URL
  • NXM_SERVER_HOST, NXM_SERVER_PORT
  • NXM_CORS_ORIGINS
