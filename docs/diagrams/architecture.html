Architecture · Diagram Design

A small facade over focused configuration modules

Applications call one public Rust surface. Internal modules resolve paths, parse settings, load files, and handle MCP server configuration.

Stable public surface

  • lib.rs re-exports the supported types and functions.
  • Internal modules stay replaceable behind that facade.
  • Consumers depend on one crate, not on file conventions.

Two configuration families

  • General platform settings use typed TOML models.
  • MCP helpers resolve JSON-first server configuration.
  • Both surfaces use the same default hidden home directory.

Explicit inputs

  • Files supply durable defaults.
  • NXM_* variables override selected values.
  • Every result is validated before it reaches callers.
